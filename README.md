# 省点 · 生活省钱 Agent 原型

## 快速体验

无需构建、无需第三方依赖。直接打开 `dist/index.html`，或在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1` 后访问 `http://127.0.0.1:4173/dist/`。

## 产品文档

[查看 HTML PRD](docs/life-saving-agent-prd.html)。下载仓库后可用浏览器打开，支持打印为 PDF。

## 已实现的原型交互

- 资产总览、分类占比、持有日均成本、状态筛选、搜索与 CSV 导出。
- 手动新增、编辑、退款金额、开始 / 结束日、售出 / 报废 / 退货状态。
- CSV 本地解析、示例导入、逐行分类、去重、错误报告与确认入库。
- 3 件示例商品、多平台模拟报价、运费与优惠拆分、新人资格重排、全新 / 二手隔离。
- 平台新增 / 编辑 / 启停与模拟连接测试。
- localStorage 保存，刷新保留；重置按钮恢复初始示例。

## 原型边界

没有真实 AI、登录、服务端数据库或电商接口。报价是固定模拟数据，没有购买链接。新增平台仅增加模拟适配器。
CSV 支持 UTF-8（可含 BOM），最多 5 MB / 5,000 行，列名见下载模板。XLSX、平台原生账单字段映射、组合订单、自动退款关联与批次撤销未实现。
数据保存在当前浏览器的当前源中，本地文件、localhost 与部署站点之间不共享数据。

## 验证记录

已在浏览器走通：新增资产（1000 - 100 元 / 30 天 = 30 元 / 天）、示例导入（3 件资产、1 笔消费、1 待确认、1 错误）、重导去重、默认全新最低价（1249 元）、新人资格重排（1229 元）、二手分组与单平台覆盖提醒、平台启用与模拟测试。JavaScript 语法检查通过。
